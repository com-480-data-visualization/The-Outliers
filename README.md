# Crowded Orbit

**A scrollytelling data visualization of every operational satellite around Earth.**
COM-480 Data Visualization Project, EPFL Spring 2026.

[🌐 **Open the live site**](https://com-480-data-visualization.github.io/The-Outliers/)
[📹 **Watch the screencast**](https://drive.google.com/file/d/19Zk9AQz502OgaFeqtOijnA-Rgr-JP9NJ/view?usp=sharing)

Earth's orbit looks empty from below, but it is one of the most crowded, unequally controlled pieces of modern infrastructure. *Crowded Orbit* tells that story in four chapters, built on top of the UCS Satellite Database (6,713 operational satellites as of January 2023) and a 3D scene that lets you actually fly through them.

---

## The story in three findings

- **75.5%** of every operational satellite was launched **since 2019**. Two thirds of those are Starlink.
- **One single company** (SpaceX) operates **~50%** of all satellites. Across all 639 operators the Gini coefficient is **0.862**.
- Public filings already approve **~80,000 satellites by 2030**, a **12× expansion** of the current fleet in seven years.

## What's on the site

| | What it is | Key interactions |
|---|---|---|
| **Hero** | 3D Earth with all 6,713 satellites on real inclined Kepler orbits, soft-glow shader, bloom post-processing. | Cinematic three-act intro. Color-coded by orbit class. |
| **Chapter 1 · The Explosion** | Cumulative-launches timeline (scroll-paced 5-step reveal) + stacked area of cumulative satellites by purpose. | Hover the timeline year for the per-year breakdown; scrolly steps animate a clip-path reveal. |
| **Chapter 2 · Who Owns Space?** | World choropleth, country bar chart, Lorenz curve (Gini = 0.862), top-10 operators bar with deep-dive drawer, country × purpose specialization heatmap. | Click any operator → slide-in panel with their full launch timeline, orbit mix, purpose mix, country. |
| **Chapter 3 · Where Is the Congestion?** | Globe.gl 3D globe + year-filter slider with play-history sweep + mega-constellation isolator (Starlink / OneWeb / Iridium / Galileo / Other) + satellite name search with pulsing-ring spotlight + orbit donut + purpose bars + purpose × orbit heatmap. | Compose any three filters (orbit × year × constellation), search by name, watch ~3 years/second of history. Selecting a constellation lights up its country on the bar chart **and** the world map. |
| **Chapter 4 · The Next Decade** | Today vs. ~2030 projection bars showing the ~12× growth filed with regulators, with an expandable Sources block citing FCC / ITU / national filings. | Hover any segment for the family's share. |

Site-wide: Lenis smooth scroll, chapter-entrance fade-ins, fully keyboard-navigable controls, `prefers-reduced-motion` respected throughout.

## Run locally

The site is fully static. Any HTTP server works. From the repo root:

```bash
cd prototype
python -m http.server 8000
```

Open <http://localhost:8000>. Hard-refresh (Ctrl+Shift+R) to bypass cache during development.

Opening `prototype/index.html` directly from the filesystem will **not** work: `fetch()` calls for the JSON data and CDN-served textures are blocked by CORS under the `file://` scheme. Always go through a local server.

---

## Regenerating the data

The two JSON files under `prototype/data/` are derived from the UCS CSV. They are committed so the site can be served statically; never edit them by hand. Re-run the build instead:

```bash
pip install -r scripts/requirements.txt
python scripts/build_data.py            # rebuild both JSONs
python scripts/build_data.py --check    # verify committed JSONs match the script
python scripts/test_build_data.py       # 23 unit + integration tests
```

The script also cleans known UCS anomalies (orbit/altitude contradictions, sign-error eccentricities, rows with corrupt orbital parameters) and writes everything it touches to [`data/data_quality_flags.md`](data/data_quality_flags.md). `--check` exits non-zero on drift so it can be a pre-commit guard.

## Tech stack

- **D3.js v7** — every chart (timeline, choropleth, heatmaps, Lorenz, operator drawer, stacked area, future projection).
- **Three.js r170** — hero 3D scene with custom GLSL shader for satellite sprites, `UnrealBloomPass` for glow.
- **Globe.gl** — Chapter 3 interactive globe with the time slider + isolator + search.
- **Lenis** — smooth scroll across the page.
- **TopoJSON + world-atlas** — Chapter 2 choropleth geometry.
- **Python / pandas / numpy** — build script.
- **No bundler.** Plain ES modules + global `<script>` tags. Open the page, it runs.

## Data sources

- **UCS Satellite Database**, Union of Concerned Scientists, snapshot 1 January 2023. Used for every chart and the 3D scene (6,713 rows after cleaning).
- **2030 projections** (Chapter 4): public regulator filings — FCC International Bureau (Starlink Gen1+Gen2, Kuiper, AST SpaceMobile, Telesat), ITU MIFR (Guowang), UK Space Agency / Eutelsat-OneWeb (OneWeb Gen2), Chinese state announcements covered by SpaceNews and Reuters (Qianfan / Spacesail). Numbers represent licensed or filed satellites, not deployed ones, as of November 2024.
